# Security policy

Do not report a vulnerability in a public issue. Use this repository's private
GitHub security-advisory route. Chadron Bryant is the accountable security
contact and maintainer.

Include the affected version, observable behavior, minimal reproduction, and
impact. Do not include credentials, tenant data, customer content, private
source files, or work-owned prompts in a public issue. Supported release
versions are listed in the repository release metadata.

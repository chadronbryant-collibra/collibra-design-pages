# Support

If installation, guidance, or an example gets in your way,
[open a GitHub issue](https://github.com/chadronbryant-collibra/collibra-design-pages/issues/new/choose).
Tell us what you tried, what you expected, and what happened. Include the
plugin version and whether you used the site, Claude Desktop Chat, Cowork, or
Claude Code. Use made-up content to reproduce the problem; leave company
files, people data, tenant details, prompts, and credentials out of the report.

## Before you report an installation problem

Confirm that the plugin is enabled under **Customize → Plugins**, start a new
session, and check that your organization allows personal plugins. See the
[installation steps](README.md#use-it-in-claude).

The supported Desktop path uses an installed Claude app on macOS 13+ or
Windows 10+, a paid plan, and personal plugins permitted by organization
policy. Linux is outside this package's supported path. Requirements were
checked on 13 October 2026 against Claude's
[Desktop requirements](https://support.claude.com/en/articles/10065433-install-claude-desktop)
and [plugin instructions](https://support.claude.com/en/articles/13837440-use-plugins-in-claude).

The suite provides guidance and offline examples. Organization-wide managed
deployment, policy bypass, external connectors, live Collibra data, and
automatic file writes are outside its scope. Source and package validation
do not establish real-device acceptance.

For a vulnerability, use the private reporting route in [Security](SECURITY.md).

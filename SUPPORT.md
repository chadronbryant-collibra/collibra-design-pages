# Support

Public GitHub issues are the planned route for installation, documentation,
and synthetic-example defects. Use only synthetic reproduction material.

Supported surfaces: Claude Desktop Chat and Cowork on macOS 13+ and Windows 10+,
paid plans, and personal-plugin environments permitted by organization policy.
Linux is outside this package's supported path. These prerequisites were
verified 2026-10-13 against the official
[Claude Desktop installation requirements](https://support.claude.com/en/articles/10065433-install-claude-desktop)
and [plugin marketplace instructions](https://support.claude.com/en/articles/13837440-use-plugins-in-claude).
Organization-wide managed deployment, policy bypass, external connectors, live
Collibra data, and automatic file writes are outside the package boundary.

Security reports use the private route in `SECURITY.md`, never a public issue.

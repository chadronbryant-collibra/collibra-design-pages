    How to read guidance status

    Defined guidance is usable within its stated boundary. Proposed guidance needs review. Open means a source or decision is missing. Deferred means it’s intentionally held. These labels don’t confirm that your own output has been reviewed or approved.

    FROM EXAMPLE TO YOUR OWN WORK

    Bring the suite into Claude.

    Install once. Tell Claude what you’re making, who it’s for, and what needs to stay true.

    1. STEP 1

      Add the help you need

      The full suite includes all six skills. Choose the standalone SOP skill if you only need guides and procedures.

      Download the suiteDownload the SOP skill

      Upload the suite in Customize → Plugins, or the SOP ZIP in Customize → Skills → Create skill → Upload a skill. Enable it and start a new conversation. You only need one download.

    2. STEP 2

      Connect your Google tools

      In Customize → Connectors, connect Google Drive, Docs, Slides and Sheets with your work Google account.

      Check the tools are enabled in your chat. Your existing Google permissions still apply.

      Google connector instructions ↗

    3. STEP 3

      Create your first guide

      Bring an existing document or answer a few questions. Name the reader and ask for a new Google Doc so your source stays intact.

      “Use collibra-sop to help me write a guide for [reader]. Ask about the process, keep its conditions and create a separate Google Doc draft.”

    Before you begin

    Use your work Claude account. Plugin and connector availability follows your organization's settings. The public page, example documents and ZIP downloads need no sign-in; using Claude and Google tools needs your own account.

    Detailed setup, Slides and Sheets examples

    Read the full setup guide on GitHub. The guide is public; you do not need a GitHub account to read it.

    Claude plugin instructions · Claude skill instructions

    What the six skills help you do
    Update, disable, or uninstall

    Open Customize → Plugins to manage the suite. After an update, start a new session. If the skills aren’t visible, confirm the plugin is enabled and personal plugins are allowed.

    Privacy, permissions, and limits

    The plugin is skills and references only. It adds no connectors, credentials, external packages, or tracking. Your prompts still go to Claude under your account’s terms and organization policy. This site uses no analytics, stores no prompt edits, and makes no AI requests. Examples use made-up content. Use only authorized material in your approved tools.

    Get help or suggest an improvement

    Open a public GitHub issue for general feedback. Don’t include company documents, prompts, people data, credentials, or private security details. See the security policy for private reporting.

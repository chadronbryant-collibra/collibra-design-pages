How to read guidance status

Defined guidance is usable within its stated boundary. Proposed guidance needs review. Open means a source or decision is missing. Deferred means it’s intentionally held. These labels don’t confirm that your own output has been reviewed or approved.

FROM EXAMPLE TO YOUR OWN WORK

Bring the suite into Claude.

Install once. Tell Claude what you’re making, who it’s for, and what needs to stay true.

Install in Claude Desktop

You’ll need an installed, supported Claude Desktop app on macOS 13+ or Windows 10+, a paid plan, and permission to use personal plugins under your organization’s policy. Requirements checked on 13 October 2026.

  1. Open Customize → Plugins.Choose Add, then Add marketplace.
  2. Add the public marketplace.chadronbryant-collibra/collibra-design-pages
  3. Install Collibra design suite.Enable it, then start a new Chat or Cowork session.
  4. Ask for the work you need.“Use collibra-create to turn this outline into a five-slide team update. Keep the facts, lead with the takeaway, and suggest a visual for each slide.”

No terminal commands or administrator password are required for personal-plugin installation when your organization permits it. The suite doesn’t bypass policy or connect to company systems.

What the plugin does

It advises, writes, and helps you adjust. It doesn’t grant asset rights, create approvals, or publish your work.

In Chat, ask for a self-contained Artifact or an outline. In Cowork, request portable files in a folder you’ve connected. Native slides and documents need an appropriate authoring tool and your approved template.

FIVE WAYS TO ASK FOR HELP

Choose the help, not the jargon.

Update, disable, or uninstall

Open Customize → Plugins to manage the suite. After an update, start a new session. If the skills aren’t visible, confirm the plugin is enabled and personal plugins are allowed.

Privacy, permissions, and limits

The plugin is skills and references only. It adds no connectors, credentials, external packages, or tracking. Your prompts still go to Claude under your account’s terms and organization policy. This site uses no analytics, stores no prompt edits, and makes no AI requests. Examples use made-up content. Use only authorized material in your approved tools.

Source and package validation are separate from real-device acceptance. The release owner waived rendered human and standard-user Desktop acceptance; no macOS or Windows Chat/Cowork installation receipt is claimed.

Get help or suggest an improvement

Open a public GitHub issue for general feedback. Don’t include company documents, prompts, people data, credentials, or private security details. See the security policy for private reporting.

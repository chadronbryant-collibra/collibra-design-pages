# Contributing

Use synthetic, public-safe material. Do not submit Collibra tenant data,
customer content, employee information, private source evidence, restricted
assets, credentials, copied prompts, or internal paths.

Changes require a pull request, current checks, and owner review. Keep the
plugin skills-and-references only: no hooks, agents, MCP servers, connectors,
executable plugin scripts, subprocesses, credentials, analytics, trackers,
remote runtime assets, or package dependencies. Add a meaningful behavior or
boundary test with each contract change.

The release licenses are Apache-2.0 for code and CC BY 4.0 for guidance or
synthetic examples. Collibra marks, logos, proprietary fonts, trade dress,
and restricted assets are excluded.

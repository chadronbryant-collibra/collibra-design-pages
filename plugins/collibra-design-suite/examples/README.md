# Synthetic examples

These examples contain no tenant data, customer material, private source
content, or recognizable source assets. Replace synthetic facts only with
content you are authorized to use.

| Skill | Copy-ready request | Expected shape |
| --- | --- | --- |
| `collibra-design` | “Choose the smallest design contract for an internal data-quality dashboard used by program leads.” | Reader-first design brief with maturity and accessibility boundaries. |
| `collibra-create` | “Create an offline executive dashboard Artifact using the synthetic data in `dashboard/data.json`.” | Self-contained editable HTML Artifact. |
| `collibra-refine` | “Refine: We have operationalized the remediation workflow and need stakeholders to action exceptions by Friday.” | Paste-ready, direct audience copy with the date condition preserved. |
| `collibra-simplify` | “Simplify: Lineage identifies upstream and downstream dependencies used to assess change impact.” | Plain-language explanation that preserves the term `lineage`. |
| `collibra-review` | “Review the dashboard example for hierarchy, keyboard access, non-color cues, responsive behavior, and evidence boundaries.” | Ranked findings without silent edits. |

See `dashboard/WALKTHROUGH.md` for the complete creation and adjustment flow.
Representative finished outputs also cover a `document/team-guide.md`,
`slide-diagram/decision-flow.svg`, `ui-flow/recovery-flow.html`, and
`content/refinement.md`.

The `web-app/` example is a runnable offline single-file prototype with a
journey, screen and state model, keyboard path, responsive reflow, and visible
loading, empty, error, ready, and long-content states. The `cross-medium/`
example applies one portable brief to a dashboard summary, message, and spoken
update while preserving fact IDs, state, and source. The `speech/` example
shows pace and estimated-duration planning without claiming an official speech
contract. Each example is synthetic and remains proposed.

HTML examples use measured palette values and clearly
labeled system-font and content-driven responsive fallbacks. Those fallbacks
are operational accessibility choices, not new Collibra brand tokens.

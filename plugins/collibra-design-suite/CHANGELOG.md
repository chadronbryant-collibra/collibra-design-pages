# Changelog

## 1.1.0 - public release, 2026-09-24

- Added the public-safe governed program-brand-extension contract so internal
  programs can adopt the shared visual system with explicit provenance,
  accessibility, usage-authority, review, channel, and deprecation rules.
- Kept named internal program sources and private assets out of the public
  registry snapshot; the public package carries only the reusable contract.
- Refreshed the visual and metadata-only registry snapshots and preserved the
  existing dependency-free, no-connector runtime boundary.

## 1.0.0 - public release, 2026-09-17

- Published the five-skill, dependency-free design suite with its synthetic
  examples, offline dashboard, licenses, SBOM, provenance, and portable package.
- Preserved the no-admin personal-plugin boundary when personal plugins are
  permitted by the user's Claude plan and organization policy.
- Recorded the accountable owner's waiver of rendered, behavioral, native, and
  real-device acceptance. Those checks were not performed and are not claimed
  as passing evidence.

  tags as prereleases in the generated public release workflow.
- Preserved final `1.0.0` gating on standard-user Claude Desktop Chat and

## 0.2.0 — 2026-09-09

- Refined the People partner and plainly useful voice lenses around early
  partnership and designing, building, and supporting useful solutions.
- Added three native guide patterns with conditional sections, links to
  existing guidance, and separate audience, delivery, and private content.
- Connected design, refinement, and review skills to the ordered design,
  Humanizer-Collibra, and audience-ready review contract without bundling a
  second copy of Humanizer-Collibra.
- Refreshed voice and visual grammar snapshots from their canonical sources.
  Package validation now rejects drift in every bundled catalog before a build
  can conceal it.

## 0.1.6 — 2026-08-29

- Added the strict, finite slide layout-geometry contract for semantic stacks,
  measured component sizes, deterministic alignment and equal gaps, governed
  zones, shape-owned insets, outside labels, leaders, and obstacle clearance.
- Kept equal-gap distribution independent from component size and made overlap
  surface-aware: semantic-content peers stay clear, while declared decorative,
  mask, or marker layering may overlap only when protected text remains clear.
- Preserved the fail-closed shorten, reflow, reduce, or split sequence; type
  downshift and native autofit remain prohibited.

## 0.1.5 — 2026-08-29

- Added a machine-readable slide type-role usage contract so substantive copy
  cannot be pushed into caption or eyebrow roles merely to make a layout fit.
- Directed generators and reviewers to preserve semantic type roles, reflow or
  reduce dense compositions, and split stories instead of making presentation
  text smaller.

## 0.1.4 — 2026-08-29

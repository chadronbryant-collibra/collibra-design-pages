# Bundled design catalog

This snapshot is generated from the private design contracts after the
public-boundary substitutions in `distribution/build_plugin.py`. It
contains the reader-facing tokens, UI, UX, visual, and content
guidance, native guide patterns, and the metadata-only registry snapshot.
The slide summary lives at `../slides-contract.md`; the public-safe,
machine-readable shape-label inset, type-role, and layout-geometry
contracts live under `slides/`.
Native template identifiers and
delivery mechanics remain consumer-owned.
